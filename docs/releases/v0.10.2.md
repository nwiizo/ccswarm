# ccswarm v0.10.2

This patch consolidates duplicated task construction and prompt rendering while
preserving their public behavior. It also updates Rustls to address
[RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285).

## Changes

- The type-state task builder reuses `TaskBuilder::parse_modifiers`. Its default
  build methods follow the existing priority/type transitions into `build`, so
  task construction has one implementation within the typed builder.
- Persona, policy, and knowledge rendering share bullet-list formatting.
  Section order, whitespace, `NEVER` markers, inline fallbacks, empty-section
  omission, and explicit raw-content overrides remain unchanged.
- Regression checks cover optional task fields and exact composed prompts.
  Runnable documentation verifies valid builder usage and rejection of
  incomplete builders at compile time.
- Development rules no longer impose arbitrary test-count limits. The updated
  rules and coding-style skill, including its references and license, are
  available under `.agents`.
- The lockfile uses `rustls 0.23.45` and `rustls-webpki 0.103.15` with the same
  dependency features.
- Update `async-trait` to 0.1.92, whose generated code fixes the
  `double_must_use` Clippy failure on Rust 1.99.
- The browser-example runner uses Playwright's own installation check, so a
  different cached Chromium revision no longer prevents required setup.

## Install

```bash
cargo install ccswarm --version 0.10.2 --locked
```

Linux and macOS archives are provided for AMD64 and ARM64, with SHA-256
checksums and GitHub build provenance.

## Scope And Limits

CLI options, configuration formats, and public Rust builder APIs are unchanged.
This release does not add provider capabilities or change Sangha decisions.
The [documented runtime limitations](https://github.com/nwiizo/ccswarm/blob/v0.10.2/docs/ROADMAP.md#known-runtime-limitations)
and existing `libyml`/`serde_yml` warnings (RUSTSEC-2025-0067 and
RUSTSEC-2025-0068) remain.
